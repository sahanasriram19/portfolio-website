Srividyalayam

A website I built for my mother’s Carnatic music school, using the school’s own photos, colours and teaching content, with an online enrolment form.

  • TypeClient project
  • Built withHTML, CSS, JavaScript
  • FormsFormspree
  • HostingVercel
Live demo ↗ GitHub ↗

How it came together

The brief

The school wanted its music and tradition to come through, using its own photography.

The content

The founder’s story, the classes and the teaching philosophy decided what each page needed.

The build

Plain HTML, CSS and JavaScript, with a shared navigation and layouts that work on a phone.

Enrolment

Every page points to the enrolment form.

A visitor can find a class, read about the founder, look through the gallery and then enrol.

What is in it

Pages

The school, the founder, the Carnatic classes and a gallery.

Enrolment form

Collects student and guardian details, class interests, experience level and availability.

Frontend

Responsive layouts, shared scripts, an active navigation link, a gallery and scroll reveals.

Client work

Built around what the school asked for, so the owner can run the front of the business herself.

I myself am cartically classically trained in indian vocal and violin so this website was deeply personal.
