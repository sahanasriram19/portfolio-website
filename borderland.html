Borderland

A wellness challenge game themed on Alice in Borderland. You do real challenges, earn points, unlock characters and buy items, and groups compete in matches using the items they own.

  • TypeCoursework project
  • Built withNode.js, Express, MySQL
  • FocusREST API and game rules
  • LoginJWT and bcrypt
Live demo ↗ GitHub ↗

The game loop

Challenge

Pick a wellness challenge, like sleeping 7 hours, and complete it.

Points

Completed challenges are the only way to earn points.

Characters

Nine characters, Chota to Mira, unlock at set point totals.

Shop

Spend points on items. Each item has a power value.

Matches

Twelve groups compete, and the one with more combined item power wins.

A match is scored in four steps: fetch the match and both groups, work out each group’s power, compare them, then save the result.

What is in it

The theme

Challenges, rewards and competition, styled after the show.

The API

Separate routes and models for users, challenges, completions, profiles, groups, matches, the shop, inventory and the leaderboard.

Rules and security

Passwords are hashed with bcrypt and routes are protected with JWT. Points only come from completed challenges.

Match logic

Small middleware functions each do one job: work out team power, compare, record the result.

The part I like most is that the scoring logic is split into pieces small enough to test.
