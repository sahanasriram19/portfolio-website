Backend and game design project

Borderland

A wellness challenge game inspired by Alice in Borderland. Real-life challenges earn points, points unlock characters and shop items, and groups compete in matches decided by their combined inventory power.

Type
Coursework project
Stack
Node.js, Express, MySQL
Focus
REST API, game logic
Status
Live
Live demo ↗ GitHub ↗

The game loop

Points can only be earned through real-world challenges, and everything else in the game is built on them.

Complete a challenge

Pick a wellness challenge, such as getting 7 hours of sleep, and mark it done.

Earn points

Verified completions award points. Nothing else in the game does.

Unlock characters

Nine characters, from Chota to Mira, unlock at point thresholds.

Buy shop items

Spend points on items that each carry a power value.

Compete in groups

Twelve themed groups battle in matches scored by combined inventory power.

Match scoring is a short pipeline: fetch the match and its groups, compute each side’s inventory power, compare the two, then resolve the match and save the outcome.

What went into it

Alice in Borderland theme

A challenge-based game with competition and unlockable rewards, styled after the show.

REST API design

Users, challenges, completions, profiles, groups, matches, shop, inventory and leaderboards each have their own routes and models.

Rules and security

JWT and bcrypt protect accounts, and verified challenge completion is the only way to earn points.

Modular match logic

Single-purpose middleware calculates team inventory strength, compares outcomes and records the result.

Takeaway

A structured game backend with clear progression, security, resource ownership and testable scoring logic.
